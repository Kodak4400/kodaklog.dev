# kodaklog.dev

kodaklog.dev は、kodak による個人的な技術ブログサイトです。

## このリポジトリについて

このリポジトリは、Next.js、TypeScript、Tailwind CSS を使用して構築された個人ブログサイトのソースコードです。主にフルスタックエンジニアとしての技術的な知見や日々の学びを共有することを目的としています。

### 技術スタック
- **フレームワーク**: Next.js 15
- **言語**: TypeScript
- **スタイリング**: Tailwind CSS
- **コンテンツ管理**: Markdown
- **ホスティング**: Cloudflare Pages

### 開発環境のセットアップ

```bash
# 依存関係のインストール
npm install
# または
bun install

# 開発サーバーの起動
npm run dev
# または
bun run dev

# プロダクションビルド
npm run build
# または
bun next build
```
